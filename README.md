# 《漢末群雄志》V0.3.0 天下完整核心版

繁體中文、原創 SVG 山河的單機回合制策略遊戲。核心循環包含內政委任、人事、外交、出征、親自守城、友城援軍及統一天下。

V0.3.0 已於 2026-11-24 正式發布。main 只提供正式網址，不再部署公開 /preview/。後續開發與發布以 [AGENTS.md](AGENTS.md) 為準；功能與驗證歷程見 [V030_STATUS.md](V030_STATUS.md)。

## 執行與驗證

需要 Node.js 24（建議）、npm 11；無後端、帳號或外部遊戲 API。

```sh
npm ci
npm run dev
```

開啟 `/hanmo-strategy/` 子路徑。正式產物可用 `npm run build` 後 `npm run preview`。

```sh
npm audit
npm audit --omit=dev
npm run typecheck
npm run test
npm run build
npm run test:browser
```

Chromium smoke 使用僅開發用的 playwright-core 和系統 Chromium。本機預設 `/usr/bin/chromium`，可設定 `CHROMIUM_PATH`；CI 使用 `/usr/bin/google-chrome`。不下載或打包瀏覽器。測試自行啟停 4174 的正式預覽，可用 `SMOKE_PORT` 改埠。

V0.3.0 正式發布 CI：197 項測試（14 個測試檔）、TypeScript、正式 PWA 建置、Chromium 回歸及離線續玩均通過。早期候選版完整及正式依賴 audit 均為 0 漏洞；詳細種子、戰役月數與限制見 V030_STATUS.md。

## 操作

1. 選劇本與諸侯。手機保留天下／城務／武將／軍情四分頁；桌面保留雙欄。
2. 天下可搜尋城市、依勢力篩選、快速選城及縮放／捲動。己方城池總覽可直接開城務；敵城顯示所屬勢力與合法相鄰出征來源。
3. 城務每月三令、每將一動：開墾、商業、徵兵、訓練、巡察、修築、調動、出征。成功後接續待命武將；不可操作時顯示原因。調動可攜兵糧，也可零兵糧移動將領；留下500守軍。
4. 城務可設定手動／均衡／經濟／軍備／防禦方針。月底只使用本城剩餘令和待命武將；設定免費，委任不擅自出征或搬運資源。月報可查每令真實成果及收支。
5. 武將分頁的人事面板提供搜尋、登用、賞賜、任命太守。搜尋／登用有機率，失敗仍花費金錢、城令及武將行動。低忠誠將領可能被鄰國招攬或離開；太守及「能吏」會提高農商效率。可依姓名、駐地、特質搜尋武將。
6. 軍情的外交面板提供贈禮、同盟、停戰及解除條約。條約有期限，確實阻止出征；AI也遵守相同限制與成本。
7. 出征軍議可選親自指揮或委任作戰；確認前不扣兵糧。可選主將與最多兩名副將；每名參戰將領都消耗本月行動。親征沿用8×6棋盤、步騎弓、克制、傷害預覽、反擊、火計、城門與十六回合限制。
8. 敵軍進攻玩家城時暫停月份，顯示警報。可親自守城或委任防守，並從至多兩座相鄰己城選援軍。確認作戰方式才扣兵、糧、城令及武將行動。親守真正控制守軍，敵軍控制攻方。
9. 部隊士氣下降會潰退；殘兵仍列入生還結算，不會憑空消失。援軍戰報記錄來源、派兵、傷亡、耗糧及返回位置。戰果只套用一次，再從原敵國處理位置繼續；所有敵國完成後才結收入及前進年月。
10. 占領全部劇本城市獲勝，失去全部城市落敗。多城世界仍須維持農業、糧食輸送與人才分布；集結大軍可能超出本城產糧能力。

完整成本與公式見 [GAME_DESIGN.md](GAME_DESIGN.md)，模組與持久化流程見 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 存檔安全

- 新遊戲寫入 `hanmo-strategy-save-v3`，schema 3。逐步保存戰術、外交、委任、月結cursor、攻城警報、援軍及亂數種子。
- 優先讀取V3。沒有V3才驗證並讀V2，再沒有V2才讀V1；舊世界遷移為legacy，城將、數值、年月、事件、戰報、委任及正在交戰的位置／種子保持原樣。
- **原V2與V1完整保留**，不強制開新局。舊戰場不補入士氣／特質或重抽地形；結束後後續新戰才使用新規則。
- 最新存檔損壞不靜默回退。可先匯出全部原檔，再明確選復原V2或V1；目前V3另存為復原備份。
- 單一瀏覽器本機存檔，無跨裝置同步。建議用一個遊戲分頁操作；多個分頁同時改同一進度未提供協調鎖。

完整長期規範見 [AGENTS.md](AGENTS.md)，優先於舊有預覽及人工驗收流程。一般改版測試成功後直接合併並發布；高風險資料操作仍須先備份與取得確認。

- 唯一網站：<https://damx2002.github.io/hanmo-strategy/>，無公開預覽版。
- Codex 在功能分支集中完成完整改版；開 PR 後自動執行 194 項以上規則測試、正式建置（含型別檢查）、V0.2.1–V0.3.0 Chromium 回歸與真正離線 PWA 測試。
- **只有 main push 在所有測試通過後自動發布 GitHub Pages**。PR 只測試、不建置兩套網站、不部署。CI 失敗阻擋發布。
- 不再要求每次發布前手機人工驗收；玩家在正式版實際遊玩，發現問題再修補。大型變更仍保持可回復的 Git commit。
- GitHub Pages artifact 只含根目錄 `dist`；不再包含 `/preview/`。

## 存檔切換與回復

- V0.2.3 正式進度位於 `hanmo-strategy-save-v2`，V0.3.0 正式進度使用 `hanmo-strategy-save-v3`。首次載入 V2 會在記憶體轉成 V3，**原 V2 字串不會刪除或覆寫**。
- 舊 `/preview/` 的 `hanmo-strategy-preview-save-v3` 保留於同一瀏覽器 origin；**絕不自動覆寫正式進度**。如果存在，開局畫面有「從舊預覽版恢復進度」可手動遷移；匯入前備份既有正式 V3。
- 正式版「匯出存檔備份」包含 V3／V2／V1 與已存在的舊預覽 V3。請將 JSON 另存至 NAS；不要清除 Chrome 網站資料或同時用多個分頁編輯同一存檔。
- PWA 更新必須完成當前戰鬥／月結，並成功儲存後才啟用新版。Git rollback 只回復程式，不能取代個人 JSON 存檔備份。

## 已知精修範圍

規則型AI和固定模板戰場不是深度搜尋；援軍為戰前選定、使用守城訓練，最多兩城，無中途行軍。外交為雙邊有限期條約，沒有複雜談判或盟友共戰。僅收錄各劇本開局可用人物，沒有完整後代出仕系統；不詳生卒／地方駐地採保守可用窗口與遊戲配置。尚無單挑、外交讓城、多人、音樂或雲端同步。

手機驗證是Chromium viewport／觸控自動化，**本次沒有重新操作實體Samsung S25 Ultra**。美術、動畫和細部平衡留待玩家回饋精修。歷次更新保留於 [CHANGELOG.md](CHANGELOG.md)。

## PWA 與離線遊玩

正式版在 `/hanmo-strategy/` 提供 Manifest、192／512 PNG 圖示、Service Worker 靜態快取、自動本機存檔及「儲存並更新」機制。Android Chrome 由正式網址安裝即可單獨啟動；首次安裝需連線，之後離線可開局、續玩。沒有雲端同步，清除網站資料或移除 App 可能使進度遺失；請定期匯出 JSON。舊預覽版網站停止更新，不再使用其獨立 Service Worker。
